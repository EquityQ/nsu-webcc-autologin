# WebCC 成都东软学院校园网自动认证插件

适用于 **Chrome** 与 **Microsoft Edge** 的 Manifest V3 浏览器插件。配置好你自己的校园网账号与密码后，即可在打开认证页或接入校园网时自动完成登录与上线。

## 功能特性

- **零第三方依赖**：基于 Chrome Manifest V3，纯原生 JavaScript 实现（内置标准 DES-ECB + PKCS7 加密模块）。
- **双触发自动上线**：
  - 访问 `https://cc.nsu.edu.cn/` 时自动检测登录态并完成登录上线与页面刷新；
  - 后台定时轮询（可配置 1 / 2 / 5 / 10 分钟），断线重连或接入校园网后自动恢复上线。
- **自定义账号与策略**：
  - 支持**学生 / 教职工账号**以及**访客手机号账号**；
  - 支持自定义首选网络套餐（连接校园网后可自动拉取可用套餐标签一键填入，留空默认选首个可用套餐）；
  - 支持单设备上限保护：**默认不自动顶掉其他已在线设备**，用户可按需在设置中开启自动顶号；
  - 支持查看在线状态、本机 IP、当前套餐、下线本机及最近运行记录。
- **安全重试保护**：账号密码错误立即暂停自动重试；遇到需要微信/钉钉扫码（`needQRLogin`）或电话语音验证时暂停 10 分钟并弹窗提醒人工处理。
- **隐私友好**：账号和密码仅保存在本机 `chrome.storage.local` 中，仅向校园网官方接口 `https://cc.nsu.edu.cn/Auth.ashx` 发起请求。

## 安装方法（Chrome / Edge）

1. 从本仓库下载源码 ZIP（点击右上角 `Code` → `Download ZIP`）或克隆仓库到本地固定文件夹（**安装后请勿删除该文件夹**）：
   ```bash
   git clone https://github.com/EquityQ/nsu-webcc-autologin.git
   ```
2. 打开浏览器的扩展程序管理页面：
   - **Chrome**：地址栏输入 `chrome://extensions/`
   - **Edge**：地址栏输入 `edge://extensions/`
3. 打开右上角 **「开发人员模式 / 开发者模式」** 开关。
4. 点击 **「加载已解压的扩展程序」**（Edge 为「加载解压缩的扩展」），选择包含 `manifest.json` 的项目目录。

## 首次使用设置

1. 点击浏览器右上角工具栏中的插件图标（建议固定到工具栏方便查看状态徽章）。
2. 选择账号类型（学生/教职工账号，或访客手机号）。
3. 填写你自己的**校园网账号**与**校园网密码**。
4. **首选套餐**（可选）：
   - 留空时默认自动选择当前账号第一个可用套餐；
   - 若账号下有多个套餐，连接校园网点击一次「刷新状态」后，下方会自动列出可用套餐标签，点击即可填入。
5. 点击 **「保存设置」**，再点击 **「立即登录上线」** 测试。

## 常见问题说明

### 1. 为什么会提示需要扫码或电话语音验证？
- **常用设备免电话验证**：学生用户首次在新设备（或新网卡 MAC）上线时，校园网可能会要求电话语音验证。建议先手动完成一次上线后，在 `https://cc.nsu.edu.cn/` 页面中将该设备设为 **「常用设备」**，之后即可免除每次上线前的电话验证（校园网规定的定期抽检除外）。
- **扫码 / 人工验证**：当后台检测到账号需要微信/钉钉扫码或电话语音验证时，插件会自动暂停后台重试 10 分钟并弹窗提醒，请打开认证页由本人手动完成验证。

### 2. 「在线设备已满时自动顶掉旧设备」是什么意思？
- 校园网一般默认限制同时在线设备数量（例如学生组常见为 1 台）。
- 插件**默认关闭**自动顶号，防止你在用手机或另一台电脑上网时被意外踢下线。
- 如果你确定希望当前电脑优先抢占网络，可以在插件设置中手动开启 **「在线设备已满时自动顶掉旧设备」**。

### 3. 密码错误会一直重试导致锁号吗？
- 不会。只要检测到账号或密码错误，插件会立即暂停自动重试，直到你在设置中修改并保存，或手动点击「立即登录上线」。

## 项目结构

```text
nsu-webcc-autologin/
├── manifest.json       # Chrome/Edge Manifest V3 配置
├── background.js       # 后台 Service Worker（定时检测、通知、状态徽章）
├── content.js          # 认证页面自动触发脚本与状态提示
├── popup.html          # 插件弹窗结构
├── popup.css           # 插件弹窗样式
├── popup.js            # 插件弹窗交互逻辑
├── lib/
│   ├── des.js          # 纯 JS DES-ECB + PKCS7 加密实现
│   └── webcc.js        # WebCC Auth.ashx 协议客户端与状态机
├── icons/              # 16/48/128 插件图标
└── tests/
    └── verify.mjs      # 加密向量与状态机单元测试
```

## 本地测试

需要 Node.js（18+），在项目根目录运行：

```bash
node tests/verify.mjs
```
